# Product Overview

This is a **Furniture Marketplace API** with an integrated referral system. The backend provides comprehensive e-commerce functionality including:

- User authentication and profile management
- Product catalog and inventory management
- Order processing and payment handling
- Referral system for user acquisition
- File upload capabilities for product images
- RESTful API with Swagger documentation

The API serves as the backend for a furniture marketplace platform, designed to handle typical e-commerce workflows while incorporating a referral program to drive user growth.

## Key Features
- JWT-based authentication with Google OAuth integration
- Comprehensive product and order management
- Payment processing integration
- User referral tracking and rewards
- File upload system for product media
- Rate limiting and security middleware
- Automated API documentation via Swagger
